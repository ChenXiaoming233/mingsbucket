# mingsbucket

Mings 的个人 Scoop Bucket，收录常用工具与应用。

## 使用方法

```powershell
scoop bucket add mingsbucket https://github.com/ChenXiaoming233/mingsbucket
```

## 收录清单

| 应用名 | 描述 |
|--------|------|
| github-desktop-zhcn | 来自 [zetaloop](https://github.com/zetaloop) 的 [GitHub Desktop 中文版](https://github.com/zetaloop/desktop) |
